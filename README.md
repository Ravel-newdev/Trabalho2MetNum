===Trabalho de Métodos Numéricos – Cordas Elástica===

Este projeto implementa métodos numéricos para resolver sistemas lineares
e analisar o comportamento de cordas elásticas por meio da Regra de Cramer.

===Métodos Implementados

- Eliminação de Gauss
- Gauss-Jordan
- Regra de Cramer

Estrutura

src/methods → algoritmos numéricos  
src/output → saída formatada  
main.cpp → controle principal  

Compilação
bash
make

execução
./bin/trabalho2

Entrada:
n (número de cordas)
a (parâmetro)
Matriz C
Vetor v

Saída:
Deslocamentos
Amplitudes
Indicação de rompimento
